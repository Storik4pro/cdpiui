# Результаты и сборка пресета

После завершения нажмите [Просмотреть результат]. Старый отчёт можно открыть через [Предыдущие подборы](cdpiui://Tools/AutoConfig/Zapret2/Reports).

Окно результата разделено на страницы [Результат подбора], [Сборка пресета] и [Диагностические сведения].

### Результат подбора

Здесь показано, как каждая стратегия сработала для каждого сайта и варианта подключения.

- **Результат**, например `5/5 (100 %)`, означает, что успешны все пять попыток.
- **Ответ**, например `45 мс`, показывает время ответа. Сначала оценивайте долю успешных попыток и только затем скорость.
- **Без Zapret2** показывает результат обычного подключения. Если сайт уже стабильно доступен без обхода, добавлять для него отдельную стратегию не требуется.
- Значок предупреждения означает, что строка прошла проверку, но стратегия не подтверждена для всех связанных вариантов подключения этого сайта.

Поиск, фильтр и сортировка помогают скрыть лишние строки. Для обычного сценария удобно выбрать успешные результаты и сортировку [Сначала самые удачные].

### Сборка пресета

CDPIUI заранее добавляет в сборку автоматически выбранные стратегии. Если результат отмечен как успешный и предупреждений нет, обычно достаточно оставить этот список без изменений и нажать [Перейти к тестированию и сохранению пресета].

Порядок строк важен: более подходящий для конкретного сайта вариант должен находиться раньше общего. Панель предупреждений сообщает о пересечениях, частичном покрытии и других возможных проблемах.

### Для продвинутых пользователей

Выбранную строку результата можно:

- повторно проверить автоматическим запросом;
- временно запустить для ручной проверки в браузере;
- добавить в сборку только для текущего сайта или для всего связанного списка;
- скопировать как отображаемую часть либо как готовую строку стратегии.

Ручная сборка полезна, когда автоматически предложенный вариант не прошёл реальную проверку. Не выбирайте стратегию только по одной успешной попытке: сравните повторяемость результата для всех нужных вариантов подключения.

Подробная пошаговая инструкция: [Сборка пресета вручную](cdpiui://Help/Zapret2ManualPresetBuilding/1ManualPresetOverview/).

### Диагностические сведения

Эта страница содержит замечания подбора и полный список сетевых попыток. Она нужна прежде всего при поиске причины ошибки или обращении в поддержку. Короткие коды замечаний являются техническими идентификаторами; ориентируйтесь на пояснение рядом с кодом.

Далее: [проверка и сохранение пресета](cdpiui://Help/Zapret2PresetSelection/5SavePreset/).
