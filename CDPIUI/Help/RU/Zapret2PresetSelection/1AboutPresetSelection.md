# Подбор пресета для Zapret2

Эта утилита помогает создать пресет Zapret2 для нужных вам сайтов. Пресет — это сохранённый набор настроек, с которым компонент будет запускаться в дальнейшем.

Утилита сама:

1. Проверяет, открываются ли выбранные сайты без Zapret2.
2. Перебирает разные стратегии — варианты настроек Zapret2.
3. Выбирает наиболее устойчивые варианты и объединяет их в один пресет.
4. Проверяет готовый пресет целиком и, если возможно, исправляет найденные несовместимости.
5. Сохраняет отчёт, чтобы к результату можно было вернуться позже.

[Показать предыдущие подборы](cdpiui://Tools/AutoConfig/Zapret2/Reports)

### Когда пригодится подбор

- Нужные сайты не открываются с уже установленными пресетами.
- Вы хотите собрать один пресет для нескольких сайтов или списков сайтов.
- Вы хотите проверить разные настройки автоматически, а не перебирать их вручную.

Для запуска утилиты компонент Zapret2 должен быть установлен в CDPIUI.

### Что важно знать заранее

- Проверяются только добавленные вами адреса. Если для работы сервиса нужны отдельные адреса изображений, видео, входа в аккаунт или API, их тоже может потребоваться добавить.
- Успешная автоматическая проверка ещё не гарантирует, что вся страница или приложение заработает. После подбора обязательно проверьте пресет обычным браузером или нужным приложением.
- Во время подбора CDPIUI временно останавливает работающие сетевые компоненты. Интернет на компьютере может быть недоступен до завершения или отмены проверки.
- Даже остановленный или частично успешный подбор обычно оставляет отчёт с уже полученными результатами.

Если автоматически предложенный вариант не подошёл, его можно изменить по инструкции [Сборка пресета вручную](cdpiui://Help/Zapret2ManualPresetBuilding/1ManualPresetOverview/).
