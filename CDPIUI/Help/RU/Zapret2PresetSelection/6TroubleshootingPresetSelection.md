# Если результат не подошёл

### Подходящий пресет не найден

1. Убедитесь, что адрес открывается без ошибок написания и действительно недоступен без Zapret2.
2. Используйте сбалансированный режим, а затем при необходимости тщательный.
3. Если выбран вариант [Одна стратегия для всего списка], попробуйте [Подбирать для каждого сайта].
4. Проверьте, что выбраны подходящие варианты HTTPS и IP.
5. Повторите подбор при стабильном подключении без смены VPN, прокси или DNS.

### Получен только предварительный пресет

Это лучший вариант из найденных, но он не прошёл полный порог для всех целей. Откройте [Диагностические сведения], найдите неуспешные сайты и проверьте их вручную. Такой пресет можно сохранить для доработки, но не следует считать полностью проверенным.

Если в отчёте есть другие успешные стратегии, попробуйте [собрать пресет вручную](cdpiui://Help/Zapret2ManualPresetBuilding/1ManualPresetOverview/).

### Автоматическая проверка успешна, но сайт не работает в браузере

Добавьте адреса, которые сайт использует для входа, изображений, видео, API или доставки содержимого. Иногда главная страница доступна, а один из вспомогательных адресов остаётся заблокированным.

Также проверьте IPv4 и IPv6. Браузер может выбрать не тот вариант IP, который был проверен утилитой.

### Сайт пропущен из-за DNS

Утилита не смогла получить сетевой адрес домена. Проверьте написание и откройте домен без Zapret2. Если он не определяется и в других программах, сначала исправьте подключение или настройку DNS, а затем повторите подбор.

### В старом отчёте отсутствует список сайтов

На странице просмотра пресета найдите файл с предупреждением и нажмите [Заменить]. Укажите текущую копию списка. Если список изменился, надёжнее запустить новый подбор.

### Подбор был остановлен или завершился ошибкой

Откройте [Предыдущие подборы](cdpiui://Tools/AutoConfig/Zapret2/Reports): частичный отчёт может содержать уже найденные стратегии. Для обращения в поддержку сохраните отчёт JSON. Перед отправкой учтите, что в нём могут быть указаны проверенные адреса и пути к вашим файлам.

### Для продвинутых пользователей

Автоматический запрос проверяет конкретный адрес, протокол и версию IP, но не полностью повторяет работу браузера. Он не проверяет загрузку JavaScript и всех дополнительных ресурсов страницы, а параметры защищённого соединения браузера могут отличаться.

Утилита предназначена прежде всего для HTTP- и HTTPS-сайтов. Голосовые соединения Discord и другой произвольный UDP-трафик приложений таким способом не проверяются.

Вернуться к началу: [Подбор пресета для Zapret2](cdpiui://Help/Zapret2PresetSelection/1AboutPresetSelection/).
