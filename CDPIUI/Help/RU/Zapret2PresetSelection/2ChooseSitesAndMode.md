# Подготовка к подбору

Подготовка состоит из трёх шагов: выбор сайтов, выбор режима и проверка дополнительных параметров.

### 1. Добавьте сайты

Нажмите [Добавить список сайтов]. Можно выбрать установленный в CDPIUI список, добавить TXT-файл, перетащить TXT-файл в окно или создать собственный список.

В собственном списке и TXT-файле указывайте по одному адресу в строке. Поддерживаются, например:

```text
example.com
https://example.org/video
```

Строки, начинающиеся с `#`, считаются комментариями и не проверяются.

Если указать только домен, утилита проверит выбранные ниже варианты подключения. Если указать полный адрес с `http://` или `https://`, проверка будет соответствовать этой схеме.

### Как обрабатывать список

Для каждого списка выберите один из вариантов:

- **Одна стратегия для всего списка** — утилита ищет общий вариант, подходящий всем сайтам списка. Пресет получается компактнее. Это хороший первый выбор для готового тематического списка.
- **Подбирать для каждого сайта** — для разных сайтов можно выбрать разные стратегии. Этот вариант полезен для смешанного списка, но подбор длится дольше, а пресет может получиться больше.

Если для списка не удаётся найти общий вариант, повторите подбор с настройкой **Подбирать для каждого сайта**.

### 2. Выберите режим

- **Быстрый** — минимальный набор вариантов и две попытки. Подходит для первого короткого запуска.
- **Сбалансированный** — расширенный набор, три попытки и дополнительная проверка готового пресета. Рекомендуется в большинстве случаев.
- **Тщательный** — полный доступный набор, пять попыток и усиленная проверка устойчивости. Может занять значительно больше времени.

Сначала используйте сбалансированный режим. Тщательный имеет смысл, если результат оказался нестабильным или подходящий вариант не найден.

### 3. Проверьте дополнительные параметры

Если вы не уверены в назначении настройки, оставьте рекомендуемое значение или нажмите [Восстановить рекомендуемые].

Для большинства современных сайтов нужны проверки HTTPS. Проверка только HTTP недостаточна: успешный ответ или перенаправление ещё не означает, что защищённая страница откроется.

- **HTTPS (автовыбор TLS)** ближе всего к обычному защищённому подключению.
- **TLS 1.2** можно добавить, чтобы проверить ещё один распространённый вариант HTTPS.
- **TLS 1.3 (точный)** предназначен для отдельной проверки именно TLS 1.3.
- **IPv4** подходит большинству подключений.
- **IPv6** включайте только при наличии рабочего IPv6 у вашего провайдера.

### Для продвинутых пользователей

- **Ожидание подключения** — сколько ждать установления соединения с сайтом.
- **Полное время запроса** — общий предел одной попытки. Он не может быть меньше времени подключения.
- **Ожидание запуска Zapret2** — пауза между запуском очередной стратегии и запросом к сайту.
- **Количество запросов к домену** — сколько раз повторять каждую проверку. Большее значение лучше выявляет нестабильный результат, но заметно увеличивает время работы.
- **Не завершать после нахождения лучших стратегий** — продолжить проверку остальных стратегий выбранного режима. Настройка увеличивает время работы и не добавляет варианты из более тщательного режима.

На странице [Проверка параметров] сверьте количество сайтов, варианты подключения и режим. Показанное время — осторожная оценка верхней границы, а не точный прогноз.
