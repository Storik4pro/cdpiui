# Области применения, порядок и предупреждения

На странице [Сборка пресета] каждая строка показывает область применения, вариант подключения и выбранную стратегию. Предпросмотр ниже пересобирается после каждого изменения.

### Управление списком

- Кнопки со стрелками перемещают выбранную строку вверх или вниз.
- [Удалить] убирает выбранную стратегию.
- [Удалить все] очищает ручной пресет.

Если для одной области добавлена одна стратегия, она становится основной. Если для той же области добавлено несколько совместимых стратегий, первая используется как основная, а следующие — как резервные варианты. Поэтому порядок строк внутри одной области важен.

Не добавляйте резервные варианты только ради количества. Каждый из них должен быть проверен для всей своей области применения.

### Область сайта и область списка

Стратегия для отдельного сайта является более точной, чем стратегия для целого списка. Если области пересекаются, конструктор помещает более точный профиль раньше общего и показывает предупреждение, чтобы вы проверили результат.

Кнопка [Принять порядок] лишь подтверждает, что вы просмотрели созданный порядок. Она не переставляет строки, не меняет стратегию и не подтверждает её работоспособность. После следующего изменения предупреждение может появиться снова.

### Как относиться к предупреждениям

- **Нет данных проверки** — повторно протестируйте стратегию для выбранной области.
- **Порог не пройден** — стратегия не показала достаточно устойчивого результата.
- **Область покрыта частично** — часть сайтов или вариантов подключения не прошла проверку. Выберите другую стратегию либо сузьте область до отдельного сайта.
- **Области пересекаются** — проверьте, какой профиль будет применяться первым.
- **Стратегии нельзя объединить** — оставьте в этой области один вариант или выберите другую совместимую стратегию.

Ошибка может не позволить создать готовый текст пресета. Обычное предупреждение не блокирует продолжение, но требует ручной проверки.

### Для продвинутых пользователей

В окне могут отображаться технические коды:

- `MANUAL_STRATEGY_UNTESTED` — для стратегии нет результатов в выбранной области;
- `MANUAL_STRATEGY_UNPROVEN` — стратегия не достигла требуемого порога;
- `MANUAL_SCOPE_PARTIAL` — проверена только часть области;
- `MANUAL_SCOPE_OVERLAP` — области содержат одинаковые подключения;
- `MANUAL_CIRCULAR_UNSUPPORTED` — выбранные варианты нельзя использовать вместе как основной и резервные;
- `MANUAL_STRATEGY_INAPPLICABLE` — стратегия не поддерживает все подключения выбранной области.
