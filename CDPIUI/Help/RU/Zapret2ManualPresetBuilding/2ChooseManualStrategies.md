# Выбор стратегий

Откройте страницу [Результат подбора]. Каждая строка относится к конкретному сайту и варианту подключения, например HTTPS через IPv4.

### Как выбрать подходящий вариант

1. Найдите нужный сайт через поиск.
2. Выберите фильтр успешных результатов и сортировку [Сначала самые удачные].
3. Сначала сравните долю успешных попыток, затем время ответа.
4. Обратите внимание на результат [Без Zapret2]. Если сайт уже стабильно доступен без обхода, отдельная стратегия ему не нужна.
5. Не используйте строку со значком предупреждения, не проверив пояснение: стратегия могла пройти только часть связанных вариантов подключения.

Наиболее надёжный кандидат успешно прошёл все повторные попытки. Результат `5/5 (100 %)` обычно убедительнее, чем `1/1 (100 %)`, потому что проверка повторялась несколько раз.

### Проверьте выбранную стратегию ещё раз

- [Протестировать через CURL] повторяет автоматические запросы и обновляет результат строки.
- [Ручное тестирование компонента] временно запускает выбранную стратегию. Пока она работает, откройте сайт в обычном браузере или нужном приложении, затем остановите тест.

Ручная проверка в браузере особенно важна, если автоматический запрос успешен, а сервис всё равно работает не полностью.

### Выберите область применения

- [Добавить для этого сайта] применяет стратегию только к выбранному сайту с таким же вариантом подключения.
- [Добавить для списка сайтов] применяет её ко всему связанному TXT-списку с таким же вариантом подключения.

Для списка выбирайте стратегию только тогда, когда она успешно работает для всех нужных сайтов этого списка. Если сайты требуют разных вариантов, добавляйте их отдельно через [Добавить для этого сайта].

Одинаковую стратегию нельзя дважды добавить для одной и той же области. После добавления она появится на странице [Сборка пресета], а предварительный текст пресета обновится автоматически.

### Для продвинутых пользователей

Автоматическая проверка повторяет конкретный сетевой запрос, но не всю работу браузера. Она не доказывает загрузку дополнительных адресов, JavaScript, видео или входа в аккаунт. Для окончательного выбора используйте и результат запросов, и ручную проверку сервиса.
