# Сборка пресета вручную

Ручная сборка позволяет выбрать стратегии из отчёта подбора самостоятельно. Она пригодится, если автоматически предложенный пресет не работает в браузере, получен только частичный результат или вы хотите заменить отдельную стратегию.

Конструктор не перебирает весь каталог заново. Он использует результаты уже завершённого подбора, но позволяет повторно проверить выбранную стратегию.

### Когда стоит использовать ручную сборку

- В отчёте есть успешные стратегии, но общий автоматический пресет не подошёл.
- Для разных сайтов одного списка нужны разные варианты.
- Автоматически выбрана нестабильная или нежелательная стратегия.
- Вы хотите оставить только проверенные вручную варианты.

Если ни одна стратегия не прошла проверку для нужного сайта, ручная сборка сама по себе не сделает её рабочей. В таком случае лучше [повторить подбор](cdpiui://Tools/AutoConfig/Zapret2/) с другим режимом или списком сайтов.

### Как открыть конструктор

1. Откройте результат только что завершённого подбора или выберите его в разделе [Предыдущие подборы](cdpiui://Tools/AutoConfig/Zapret2/Reports).
2. В окне [Как продолжить?] выберите [Ручная сборка].
3. Если это окно уже закрыто, откройте страницу [Сборка пресета] в верхней части результата.

Конструктор сначала показывает стратегии, выбранные автоматически. Их можно оставить как основу, изменить или удалить кнопкой [Удалить все] и начать с пустого пресета.

Каждую добавленную стратегию обязательно проверьте на том сайте и варианте подключения, для которого собираетесь её использовать.

Далее: [выбор стратегий](cdpiui://Help/Zapret2ManualPresetBuilding/2ChooseManualStrategies/).
