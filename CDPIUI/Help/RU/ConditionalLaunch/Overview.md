# Условный запуск

Условный запуск выполняет выбранные действия по горячей клавише или при запуске и остановке процесса. Задачи продолжают работать, когда главное окно CDPI UI закрыто.

### Как устроена задача

У задачи есть триггеры и действия.

Триггер запускает задачу. Если триггеров несколько, достаточно срабатывания одного из них.

Действия выполняются по порядку сверху вниз. Например, задача может применить пресет, подождать несколько секунд и запустить компонент.

### Приоритет

Если одно событие подходит нескольким задачам, выполняются задачи с самым высоким приоритетом. При одинаковом приоритете выполняются все подходящие задачи.

### Что важно помнить

- Отключённая задача не реагирует на триггеры.
- Выберите [Выполнить], чтобы проверить задачу вручную.
- Для триггера процесса можно задать задержку. Если процесс вернётся в прежнее состояние до окончания задержки, задача не запустится.
- Для переноса задачи на другой компьютер используйте файлы `.cdpitask`.

Далее: [Создание и изменение задач](cdpiui://Help/ConditionalLaunch/CreatingTasks/).
