# Создание и изменение задачи

Откройте [Условный запуск] на странице [Утилиты].

### Создание задачи

1. Нажмите [Создать задачу] на панели инструментов.
2. На странице [Общие] укажите имя и приоритет.
3. Оставьте флажок [Выполнять задачу при срабатывании триггера], если задача должна быть активна.
4. Выберите, нужно ли останавливать задачу после ошибки.
5. На странице [Триггеры] добавьте условие запуска.
6. На странице [Действия] добавьте нужные действия и расположите их в правильном порядке.
7. Нажмите [ОК].

Приложение автоматически предлагает уникальное имя. При необходимости его можно изменить.

### Изменение и проверка

Дважды щёлкните по задаче, чтобы изменить её.

Выберите задачу и нажмите [Выполнить], чтобы проверить её без ожидания триггера.

### Импорт и экспорт

Выберите [Импорт] или [Экспорт] на панели инструментов. Одна задача хранится в одном файле `.cdpitask`.

Далее: [Триггеры и действия](cdpiui://Help/ConditionalLaunch/TriggersAndActions/).
