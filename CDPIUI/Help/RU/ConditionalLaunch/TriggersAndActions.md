# Триггеры и действия

### Триггеры

Доступны три вида триггеров:

- [Горячая клавиша] запускает задачу по выбранной комбинации клавиш.
- [При запуске процесса] запускает задачу после появления процесса.
- [При остановке процесса] запускает задачу после завершения процесса.

Для процесса можно указать имя с расширением `.exe` или без него. Задержка позволяет убедиться, что состояние процесса не изменилось случайно.

Несколько триггеров работают по правилу ИЛИ: задача запускается при срабатывании любого из них.

### Действия

Выберите действие из списка и заполните показанные поля. Лишние поля приложение скрывает автоматически.

Действия выполняются сверху вниз. Кнопки со стрелками меняют их порядок.

Простой пример:

1. Добавьте триггер [Горячая клавиша].
2. Выберите сочетание клавиш.
3. Добавьте действие [Запустить компонент].
4. Выберите установленный компонент.
5. Сохраните задачу и нажмите [Выполнить] для проверки.

Если установлен флажок [Останавливать задачу при ошибке действия], оставшиеся действия после ошибки выполняться не будут.
