# Отсутствующие файлы

Некоторые пресеты используют отдельные списки сайтов, BIN-файлы или LUA-библиотеки. Если мастер не нашёл такой ресурс по ожидаемому пути, он попросит выбрать решение. Без решения для каждого отсутствующего файла продолжить сохранение нельзя.

### Доступные действия

- **Применить автокоррекцию** — использовать файл, который CDPIUI нашёл в другой подходящей папке. Перед применением проверьте предложенный путь.
- **Выбрать вручную** — указать существующий файл самостоятельно. Лучше использовать ресурс из того же набора пресета и с ожидаемым расширением.
- **Создать пустой** — сохранить пустой файл вместо отсутствующего.

Пустой файл подходит только тогда, когда ресурс действительно необязателен. Например, некоторые пользовательские списки или файлы журнала могут начинаться пустыми. Не заменяйте обязательную LUA-библиотеку или BIN-файл пустой заглушкой, если автор пресета явно не разрешил это.

Для файлов, в названии которых есть `user` или `debug`, мастер может сразу предложить создание пустого файла. Это подсказка, а не гарантия совместимости.

Если для всех оставшихся файлов есть предложения автокорректора, нажатие **Продолжить** применит их автоматически. Если хотя бы для одного файла предложения нет, сначала выберите действие вручную.

При сохранении нужные ресурсы копируются в отдельное хранилище CDPIUI. Исходные файлы остаются на прежнем месте и не удаляются.
