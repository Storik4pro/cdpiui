# Выбор и подготовка файлов

1. [Откройте утилиту импорта](cdpiui://Tools/ImportConfig) и нажмите **Далее**.
2. В окне выбора файлов укажите один или несколько пресетов.
3. Дождитесь завершения анализа. При импорте нескольких файлов мастер обрабатывает их по очереди и показывает имя текущего файла.

### Как выбрать правильный формат?

- Выбирайте `.bat` или `.cmd`, если пресет распространяется как готовый сценарий запуска.
- Выбирайте `.txt`, если файл содержит параметры запуска компонента.
- Выбирайте `.json`, только если это экспортированный пресет CDPIUI или совместимый пресет старого формата.

Если рядом с основным файлом находятся папки `lists`, `bin`, `fake` или `lua`, оставьте структуру набора без изменений до завершения импорта. Так мастеру будет проще найти используемые ресурсы.

### Что произойдёт после анализа?

- Если нужные зависимости найдены, откроется страница результатов.
- Если некоторых файлов не хватает, сначала появится страница **Отсутствующие файлы**.
- Если файл не удалось распознать, его карточка останется на странице результатов со статусом **Не удалось**. Нажмите на статус, чтобы увидеть причину.

### Для продвинутых пользователей

Мастер не является полноценным интерпретатором командной строки Windows. Он ищет понятный запуск установленного компонента и извлекает его параметры. Файл с несколькими возможными запусками, сложными условиями, циклами или динамически собранными командами может потребовать упрощения. Для обычного BAT/CMD лучше оставить один однозначный запуск компонента.

Далее: [что делать с отсутствующими файлами](cdpiui://Help/ConfigImport/3ResolveMissingFiles/).
