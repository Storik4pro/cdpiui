# Импорт пресетов из файлов

Утилита помогает перенести в CDPIUI пресеты из других программ или из сохранённых файлов. Она распознаёт параметры запуска, находит связанные списки и библиотеки, а затем позволяет проверить и сохранить результат.

[Открыть утилиту импорта](cdpiui://Tools/ImportConfig)

### Какие файлы поддерживаются?

- `.bat` и `.cmd` — сценарии запуска компонентов;
- `.txt` — готовые параметры запуска;
- `.json` — пресеты CDPIUI поддерживаемого формата.

Можно выбрать сразу несколько файлов. Для каждого из них мастер создаст отдельную карточку результата.

Обычный JSON-документ, отчёт другой утилиты или файл настроек неизвестного формата не является пресетом CDPIUI и может не импортироваться.

### Что нужно подготовить?

- Установите в CDPIUI компонент, для которого предназначен пресет. Неустановленные компоненты недоступны для выбора и проверки.
- Не отделяйте BAT-, CMD- или TXT-файл от папок со списками, BIN- и LUA-файлами. Мастер попробует найти и перенести эти зависимости.
- По возможности сохраните резервную копию исходного набора.

### Безопасен ли анализ?

При анализе CDPIUI только читает выбранные файлы. Исходный BAT- или CMD-сценарий не запускается, команды из него не выполняются, а исходные файлы не изменяются и не удаляются.

Кнопка проверки на странице результатов работает иначе: она действительно запускает выбранный установленный компонент с импортированными параметрами. Используйте её только для файлов из источника, которому доверяете.
