# Проверка и сохранение

На странице **Импорт завершён** каждому выбранному файлу соответствует отдельная карточка. Перед сохранением проверьте её поля.

### Название и компонент

- Измените название, если имя файла недостаточно понятно. Под этим названием пресет появится в параметрах компонента.
- Убедитесь, что выбран правильный компонент. В списке показаны только установленные компоненты.
- Если появилось жёлтое предупреждение о несовместимости, выберите компонент, для которого создан пресет. Игнорируйте предупреждение только тогда, когда точно знаете, что параметры совместимы.

### Статус и подробности

- **Готово** — мастер не обнаружил проблем, блокирующих сохранение.
- **С предупреждениями** — сохранение доступно, но результат нужно внимательно проверить.
- **Не удалось** — ошибка блокирует проверку и сохранение.

Нажмите на статус, чтобы увидеть подробности и код проблемы. Предупреждение не означает, что пресет обязательно не работает, а статус **Готово** не заменяет реальную проверку нужных сайтов.

### Проверка пресета

Кнопка с треугольником запускает выбранный компонент с импортированными параметрами. Проверьте доступ к нужным сайтам, затем нажмите кнопку ещё раз, чтобы остановить тест.

Во время проверки уже запущенный экземпляр этого компонента будет остановлен. После теста прежний пресет автоматически не восстанавливается — при необходимости снова запустите его в обычных параметрах компонента.

Тест запускает реальный исполняемый файл установленного компонента и не является песочницей.

### Сохранение

- Кнопка с дискетой сохраняет одну карточку.
- **Сохранить все** последовательно сохраняет все готовые карточки.
- Успешно сохранённые карточки исчезают из списка. Карточки с ошибкой остаются, чтобы можно было открыть подробности.

После сохранения выберите новый пресет в параметрах соответствующего компонента. Если пресет содержит дополнительные переключатели или значения, настройте их перед обычным запуском.

### Для продвинутых пользователей

При выборе Zapret2 для пресета Zapret Legacy мастер умеет преобразовать готовые параметры `winws` в `winws2`. Обратное преобразование из Zapret2 в Zapret Legacy не поддерживается. Для других несовпадающих компонентов специальная конвертация не выполняется.

Если что-то не получилось: [ошибки и ограничения](cdpiui://Help/ConfigImport/5ConfigImportTroubleshooting/).
