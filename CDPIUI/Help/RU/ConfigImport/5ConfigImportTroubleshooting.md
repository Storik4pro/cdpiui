# Ошибки и ограничения

Если карточка имеет статус **С предупреждениями** или **Не удалось**, нажмите на статус. Откроется описание с кодом проблемы и, когда это возможно, номером строки исходного файла.

### Частые ситуации

**JSON-файл не поддерживается**

Утилита принимает JSON-пресеты CDPIUI поддерживаемого формата. Произвольный JSON, отчёт подбора Zapret2 или настройки другой программы нельзя импортировать только из-за расширения `.json`. Найдите экспортированный пресет либо используйте BAT, CMD или TXT с параметрами запуска.

**Не удалось определить или выбрать компонент**

Сначала установите нужный компонент через Магазин CDPIUI. Компонент доступен мастеру только тогда, когда его папка и исполняемый файл существуют на компьютере.

**Пресет не подходит выбранному компоненту**

Выберите компонент, указанный автором пресета. Похожее назначение компонентов не означает одинаковый набор параметров.

**Не найден связанный файл**

Вернитесь к исходному архиву или папке пресета и найдите требуемый список, BIN- или LUA-файл. Выберите его вручную. Создавайте пустой файл только для действительно необязательного ресурса.

**Не найден запуск компонента или найдено несколько запусков**

Мастер не смог однозначно выделить параметры. Попробуйте другой файл из набора, удалите лишние варианты запуска из копии BAT/CMD либо сохраните нужные параметры в отдельный TXT-файл.

**Тест сразу завершился или пресет не работает после сохранения**

Проверьте выбранный компонент, предупреждения и решения для отсутствующих файлов. Убедитесь, что импортирован именно рабочий вариант запуска. Некоторые пресеты требуют дополнительных значений, которые нужно настроить в параметрах компонента.

### Для продвинутых пользователей

Статический анализ может обработать только известные конструкции. Сложные `if`, `for`, `goto`, вычисляемые переменные, нестандартные подключаемые файлы, запуск через обёртку и произвольное создание ресурсов могут быть распознаны частично. Команды исходного BAT/CMD при анализе не выполняются, поэтому результат такого сценария иногда приходится исправлять вручную.
